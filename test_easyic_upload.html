修复说明：

问题原因：

  • 前端传递的 headers 中包含 Content-Type: multipart/form-data; boundary=...
  • 这个 boundary 是前端请求 Django 时使用的
  • Django 转发时，requests 库会自动生成新的 boundary
  • 但我们手动传递了旧的 Content-Type，覆盖了 requests 自动生成的
  • 导致目标服务器收到的 boundary 不匹配，无法解析文件

修复方案：

  • 在转发前，从 headers 中移除 Content-Type
  • 让 requests 库自动生成正确的 Content-Type 和 boundary
  • 这样目标服务器就能正确解析 multipart/form-data 请求
